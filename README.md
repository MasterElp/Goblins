# Goblins
World simulator

# Главная идея

- Проект представляет собой автономную симуляцию живого мира.
- Основой проекта является не игровой процесс, а моделирование мира, который способен существовать, развиваться и изменяться независимо от присутствия игрока.
- Игрок не является центром мира. Он лишь один из возможных наблюдателей или участников происходящих событий.

Симуляция мира. Архитектура и философия проекта — в `docs/`.

## Сборка

```
mkdir build && cd build
cmake ..
cmake --build . -j
```

Зависимости (EnTT) подтягиваются автоматически через CPM.cmake при конфигурации — интернет нужен только на этом шаге.

## Запуск

```
./server/goblins_server [кол-во тиков]
```

По умолчанию — 10 тиков. Программа создаёт Область 100x100, случайно
размещает 40 непроходимых булыжников (без коллизий по тайлам), затем
запускает игровой цикл и печатает номер каждого тика.

## Структура

- `core/` — ядро симуляции: ECS (EnTT), компоненты, системы, игровой цикл, генерация мира. Не зависит от server/clients.
- `server/` — исполняемый файл, оборачивающий core. Сетевой слой (WebSocket) появится на следующих этапах.
- `clients/` — будущие десктопный и браузерный клиенты.
- `docs/` — архитектурные документы проекта.
